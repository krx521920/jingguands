## 2. 函数契约

`normalize(input: MeasureInput): NormalizedMeasure`

- 输入字段：`kind`（`amount | shares | ratio`）、`rawText`、`rawValue`（十进制字符串，无千位分隔符）、`sourceUnit`、`qualifier`、`scope`、`status`、`denominator`。
- 输出在输入基础上新增 `value`（换算后十进制字符串，`null` 表示无可用数值）与 `unit`（标准单位：元 / 股 / %）。
- 全部数值以十进制字符串运算，**禁止二进制浮点数**，故 `0.00000001 亿元` 精确等于 `1 元`。

换算系数（十进制移位 `×10^places`）：

| kind | 源单位 → 标准单位 | places |
| --- | --- | --- |
| amount | 万元 → 元 | 4 |
| amount | 亿元 → 元 | 8 |
| shares | 万股 → 股 | 4 |
| shares | 亿股 → 股 | 8 |
| ratio | % → % | 0（百分点数，不再乘 100） |

## 3. 三种状态：缺失 / 零 / 无法读取

| status | 含义 | `rawValue` / `value` | 处理 |
| --- | --- | --- | --- |
| `not_mentioned` | 已核验范围内原文未提及 | `null` / `null` | 不计算、不填充；不得携带数值 |
| `explicit_zero` | 原文明确写明零（可核验零值） | `"0"` / `"0"` | 可参与计算；必须 `qualifier=exact` |
| `unreadable` | 来源存在但扫描/OCR/表格无法可靠读取 | `null` / `null` | 降级转人工，不得猜测或填零 |

`null`（JSON 空值）与 `"0"`（数值零）不可混用。`status=present` 且精确为零必须改记 `explicit_zero`；`not_mentioned` / `unreadable` 携带数值会被拒绝，防止把残留数字当成结果。

## 4. 校验与拒绝规则

- `kind`、`status`、`scope` 不在枚举内 → 拒绝。
- `present` / `explicit_zero` 必须给 `rawText`、合法 `rawValue`、支持的 `sourceUnit`、合法 `qualifier`，否则拒绝。
- `ratio` 有值必须带非空分母；非 `ratio` 携带分母 → 拒绝。
- `shares` 换算后出现小数股 → 拒绝（必须是整股）。
- 精确零必须用 `explicit_zero`；`explicit_zero` 必须是精确零。

## 5. 20 组用例清单

| 编号 | 场景 | 核验重点 |
| --- | --- | --- |
| 01 | 12.34 元 | 元不变 |
| 02 | 约 1.25 万元 → 12500 元 | 万元换算、约数保留 |
| 03 | 不超过 0.15 亿元 → 15000000 元 | 亿元换算、上界不当精确值 |
| 04 | 123 股 | 股不变 |
| 05 | 累计 1.25 万股 → 12500 股 | 万股换算、累计标记 |
| 06 | -0.00000001 亿股 → -1 股 | 亿股换算、负方向、整股 |
| 07 | 2.5% → 2.5 | 百分点数，不乘百 |
| 08 | 20%（占持股）/ 3.25%（占净资产） | 两种分母分开保存 |
| 09 | 金额未提及；股数为 0 股 | 缺失 ≠ 零 |
| 10 | 比例单元格无法辨认 | 无法读取 ≠ 未提及 |
| 11 | -2.5 万元 → -25000 元 | 负数金额 |
| 12 | 3.5 亿元 → 350000000 元 | 亿元多位小数 |
| 13 | 1.2300 万元 → 12300 元 | 去尾零、无浮点误差 |
| 14 | 1.5 亿股 → 150000000 股 | 亿股换算 |
| 15 | -1.25 万股 → -12500 股 | 负数万股、整股 |
| 16 | 0.005% → 0.005 | 小百分比不乘百 |
| 17 | 0 亿元 → 0 元 | 零值经单位换算仍为零 |
| 18 | 0% → 0 | 零比例 ≠ 缺失 |
| 19 | 股数未提及 | 缺失股数 ≠ 零股 |
| 20 | 金额单元格无法辨认 | 无法读取金额 ≠ 缺失 |

另含 8 条拒绝用例：缺失/无法读取携带数值、比例缺分母、分母定义为空、非比例带分母、小数股、不支持单位、精确零误标 `present`、`explicit_zero` 非零。
