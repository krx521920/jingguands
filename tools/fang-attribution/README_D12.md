## 修复与计算口径

| 问题 | 修正规则 | 公开受控回归 |
| --- | --- | --- |
| 税率数字片段误命中 | `16%` 不能为 `6%` 提供依据；只接受“税率”后完整数字，同引文出现不同税率时保留疑点。税后金额仍精确计算为未税金额 × (1 + 税率 / 100)，不倒推税率。 | T01–T06 |
| 汇率左端基数误命中 | `11 AED = 2 CNY`、`-1 AED = 2 CNY` 不能截取为 `1 AED = 2 CNY`。仍需同事件、同观察日、同税口径及可验证原文。 | F01–F04 |
| 近似金额漏检或提前闭合 | 在换汇、换税、合计等成功分支前检查 raw 与原文中修饰当前数值的限定词；正文“约100”不能因 raw 丢了“约”而判冲突。避免把“合约100”中的“约”误判为近似。 | T06、F04、Q01–Q04 |
| 舍入使用了错误单位 | 精度以原文披露单位为准：万元保留 2 位对应基准元的 -2 位（百元），亿元保留 2 位对应 -6 位（百万元）。例如 12345 元可舍入为 1.23 万元；12350 元应为 1.24 万元，不能凑成 1.23。无明确舍入声明仍不采用容差。 | R01–R07 |

运算保持 BigInt 和有限十进制字符串，不通过 Number 求金额、股数或税额。`roundHalfUp` 的有效位范围扩为 -8…30，正负半值均远离零；零值与负零有明确处理。大于安全整数范围的 Number、科学计数法、超过现有 120 字符上限的结果返回 null，不静默截断。本轮没有放宽输入长度上限。

限定词检查是有界文本规则，不是完整自然语言解析；本回归验证列出的表达及数字绑定，不宣称覆盖任意修辞和排版。没有引入浮点容差、自动联网汇率、默认税率或个人金额分摊。
