# 项目成果与能力边界补充

可信公告事件提取与跨文档核验 | 2026-10-18

本文是原项目计划书的成果附页，供交付说明与答辩核对使用；不是全员签字确认的终稿。范围以本页列明的样本、分母和验证方式为限，最终提交版本由交付清单另行登记。

## 已形成的成果

系统覆盖质押、股权变动和中标合同三类公告事件。当前页面可查看已有结果、导入事件信封 JSON、定位字段对应的解析原文、查看跨文档核验材料，并导出 JSON 与 CSV。合计核验展示各个加数和合计的来源；受控案例与公开开发用例分开标记，证据不足时保留待复核状态。

页面显示的原文是解析文本与块、页码等定位信息，不等于原始 PDF 图像预览。JSON 导入是载入既有输出，不会触发新抽取；导入后可查看和导出该数据集。服务支持离线查看模式，真实新抽取需要配置有效密钥并启动抽取服务。

## 成绩与分母

| 指标 | 结果 | 解释 |
|---|---|---|
| 字段值一致率 | 436/437 = 99.77% | 分母是信封填值数，基于当前金标 v1.3；多填 1 处 |
| Gold 期望字段召回率 | 436/438 = 99.54% | 分母是金标期望字段数；漏抽 2 处，须与上一行分列 |
| 严格原文出处命中率 | 432/451 = 95.79% | 引文须属于指定解析块的原始子串；空白归一后的命中不能替代本指标 |
| 弃权复核覆盖 | 155/169 已复核 | 142 成立、2 漏抽、11 待裁定；另有 14 项无 Gold 不可核 |
| 已判定弃权正确率 | 142/144 = 98.61% | 只计算已裁定的 144 项；待裁定与不可核项不能算正确 |

以上字段与出处指标来自 D11 首测冻结公开语料，含 31 份信封中的 1 份扫描降级件。不同指标有不同计数单位，不能合并成“全库 100%”。当前金标与已见公开样例的高分不证明陌生公告泛化能力。
