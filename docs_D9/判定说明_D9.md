# D9 判定说明

本说明对应 `docs_D9/validation_D9/public_report_D9.json`。规则只依据sides与来源，不读取期望标签。解释“口径不可直接比较”与“差额已精确勾稽”分别记录，不能混用。

## 六类口径规则

| 维度 | 可判定依据 | 无依据时 |
|---|---|---|
| 单位 | 原文明示股/万股/亿股、元/万元/亿元；继承已标准化A单位，精确缩放副本 | 不凭1万倍/1亿倍猜单位；比例fraction不静默当百分点 |
| 币种 | 明确币名/同事件currency；明示双币金额分别记录；主动换算另需方向、日期、正汇率和同税口径 | 不从所在地、元/$、两个总额之比推币种或汇率 |
| 税口径 | 明确含/不含税；两金额换算需同币种、同事件、同观察和明示适用税率 | 未说明则未知，不倒算、不调税率凑数 |
| 分母 | A denominator或有出处的明确范围；比较百分点前核对分母 | 不倒推分母；不同分母只能解释不可比 |
| 累计 | 本次/累计字段或表头；合计另需完整且去重的成员与原值 | 不将两数相等当“合计=其余之和”；不以累计减本次造历史值 |
| 时间 | 同原子事件的同一业务位置，或带角色的明确观察日/期间 | 不把发布日期当观察日；不以对侧出现相同数字推正常进展 |

复杂税制、未明确复合税费、跨币种且税口径同时变化、区间包含关系、隐含汇率、推断更正目标、拆分联合体金额均不自动处理。输入只证明部分口径时仍保留尚未解释部分。单个日期不同的“时间口径差异”不表示已解释金额变化的经济原因。
