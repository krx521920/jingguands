## 二、分类维度

解析/出处错误落在四个维度上，逐维判定后可组合出具体类别：

### 维度 A：症状

| 症状 | 观测方式 |
| --- | --- |
| `A1 丢字` | `check_evidence.py` 报「未覆盖 > 0」 |
| `A2 重复覆盖` | 报「段落×段落重叠 > 0」（致命） |
| `A3 块错切` | 报「区域重建不一致」（块声称的 ≠ region 里实际的） |
| `A4 出处缺失` | 信封的 `provenance` 无 `block_id`，或缺 `quote` |
| `A5 出处指错` | `quote` 不在其 `block_id` 所指的块里 |
| `A6 列语义丢失` | 该有 `header_path` 的单元格没有 |
| `A7 表格未检出` | 文档里明显是表，`tables` 为空 |

### 维度 B：成因（**这一维决定归属谁修**）

| 成因 | 判据 | 归属 |
| --- | --- | --- |
| `B1 源 PDF 版面` | 绘制线缺失、无框表、扫描件 | 解析层（能力边界） |
| `B2 解析缺陷` | 有可用的几何信息却没切对 | **我修** |
| `B3 跨版本漂移` | `block_id` 指向当前版本的另一块 | **对方重锚定**（我提供修正） |
| `B4 表示层差异` | 只差空白/换行 | 消费方做归一（我已在边界表写明） |
| `B5 抽取侧` | 出处对、值错 | 魏/方修 |

### 维度 C：影响面

`C1 阻断`（整份文档解析失败或该文档全部字段不可用）·
`C2 高影响`（某类字段系统性取错）·
`C3 局部`（个别块）·
`C4 边界`（不达标但已知、有文档）

### 维度 D：是否已知

`D1 已在能力边界表登记` · `D2 新发现`

## 三、最小复现的方法

**原则：不用整份公告复现，压到能跑单页的最小输入。**

| 步骤 | 做法 |
| --- | --- |
| 1 定位页 | 由失败块的 `region` / `page` 确定页码 |
| 2 抽单页 | 用原 PDF 截出该页（保持坐标不变，便于比对） |
| 3 判可复现 | 单页能否复现同一症状；能 → 缩小到页；不能 → 是跨页/上下文相关 |
| 4 合成最小件 | 若涉及特定版面（如无框表），造合成 fixture 固定该版面 |
| 5 固化为回归 | 加 `tests/fixtures/` ＋ 一条断言该症状的用例 |

**已有先例**（可直接照搬做法）：

- `tests/fixtures/twocol_synthetic.pdf` —— 双栏正例
- `tests/fixtures/scanned_synthetic.pdf` —— 扫描降级
- `tests/fixtures/borderless_table.pdf` —— 无框表格边界
- `tests/fixtures/equity_change_synthetic.pdf` —— 变动前后多层表头

**每一条最小复现都必须带「预期」**：不是「它坏了」，而是「它应该输出什么」。
没有预期的复现只能说明现象，不能驱动修复。

1. **先分层**（对应 D11 完成标准「按事件/真实合成/文本扫描分层」）——
   合成与扫描样本的问题**不与真实文本混算**

4. 每条修复附最小复现 ＋ 回归用例
5. **未达标的如实登记**，不裁剪分母
