## 二、方式 A：全链实时（演示用这个）

### 第 1 步：取代码

```bash
git clone <仓库地址> jingguands
cd jingguands
git checkout zhangzhibo        # 新页面在这个分支的 workspace/zhangzhibo/ui_redesign/
git rev-parse HEAD             # 记下 SHA，写进演示记录
```

### 第 2 步：起后端（页面数据源）

```bash
cd workspace/cjh/page_prototype
node server.js
# → http://127.0.0.1:8642
```

**看到这行就算起好了**：
```
[cjh-page-prototype] 引擎 file  [就绪] 本地预生成信封 — …
```

### 第 3 步：起新页面

**另开一个终端**：

```bash
cd workspace/zhangzhibo/ui_redesign
node server.js
# → http://127.0.0.1:8762
```

默认就把 `/api/*` 反代到 8642 ✓ **不用配任何环境变量。**

### 第 4 步：验三件事

```bash
curl -o /dev/null -w "%{http_code}\n" http://127.0.0.1:8642/
curl -o /dev/null -w "%{http_code}\n" http://127.0.0.1:8762/
curl -s http://127.0.0.1:8762/api/metrics | head -c 200
```

**三个都该是 200 / 有 JSON。** 若第三个报「上游不可达」→ 后端没起或端口不对。

## 四、会遇到的坑（都不是环境问题）

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 传 PDF/TXT 报「仅接受 .json 信封文件」 | **设计如此**，页面不做在线抽取 | 走下拉开数据集 |
| 指标卡全 null | `data_unified/` 空 | 确认该目录有 **32 份** |
| 「模拟数据」横幅常驻 | **文案未改**（已知） | 数据是真的，忽略它 |
| 按 `D5-EQC-001` 这类名字打不开 | 该名不在下拉框 | 用 `wei_real_*` 别名 |
| 端口 8642/8762 被占 | 之前起过没关 | `pkill -f page_prototype/server.js` 后重起 |
