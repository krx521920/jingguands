原交付日期：2026-10-05，原规则版本 D9.1。2026-10-08 的 D12 修补将现有入口升级为 D12.1，详见 `README_D12.md` 与 `回归记录_D12.json`；以下 D9 成绩保留为历史基线。

已实现单位、币种、税口径、分母、累计、时间六类归因，并接入 D8 事件对齐、合计明细勾稽、更正关联和魏的插件接口。缺少证据输出 `insufficient`，疑点保留；不回写 A、不倒推汇率/税率、不拆分个人金额。

## 运行

运行环境：**Node.js 24.x**（实测 v24.21.0）；无 npm 安装、无 API Key、无网络依赖。D7 `.mts` 由 Node 原生类型剥离运行，Node 20 不在支持范围。

在本文件所在目录打开 PowerShell：

```powershell
node .\tests_D9\verify_D9.mjs
node .\src_D9\run_D9.mjs --out .\docs_D9\validation_D9\public_report_D9.json
```

`verify_D9.mjs` 同时报告“回归通过”和“原20案严格评分FAIL”，两者含义不同。它会更新验证日志；重新运行后如需分发，请重算交付清单哈希。源引用的哈希仍应全部一致。

新增文件均用 `_D9` 后缀；`vendor_D8` 保留 D8 原文件名以保证相对路径引用，属于兼容性例外。旧 D1–D8 文件和集成仓库均未改写。
