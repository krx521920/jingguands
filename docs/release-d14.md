## 一、这是什么

**可信公告事件提取与跨文档核验智能体**：把公告里的每个数、每个主体钉回原文块（A 流）；
两份公告是不是同一件事、差异能不能解释（B 流）——证据说了算，无依据不填值，证据不足不硬判。

- **工作流 A**：单文档抽取，三类事件（质押/股权变动/中标）37 字段 v0.3 契约，块级出处
  （block_id/页/区域/表格 cell/引文），扫描件诚实降级零编造
- **工作流 B**：跨文档同事件三态判定＋一致性核验（互证/矛盾/勾稽/互补）＋先归因后矛盾
  （方 D12.1 规则库为正典：币种/含税/累计/合计/舍入/近似值限定词……不能解释保留疑点）

## 四、已知边界（如实登记，不装没有）

1. 冷跑间 note/引文装饰层与事件顺序存在模型抖动（值层稳定；缓存重放完全消除）
2. 首测冻结信封无信封三键（D12 前产物，不重造；新批次起全带）
3. 解析产物跨源码版本不可字节复现（张 B1；锁语义已按宗 D13-A 裁定升级 v2）
4. `guarantee`（银行担保）不进 v0.3——范围外如实登记（宗 D13-C1 裁定）
5. text 字段 `standardized` 键无契约含义，消费方不得读取（宗 C2 裁定）
6. 页面现场导入仅收 JSON 信封（PDF→解析属张 finstruct 链路，N09 HTTP 入口供真实抽取）
7. 评测侧无模型密钥：冷跑由抽取侧执行、评测侧核信封（宗 D13 登记）
