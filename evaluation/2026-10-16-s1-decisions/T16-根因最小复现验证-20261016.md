# T-16 根因最小复现：独立验证（评测侧）· 2026-10-16

魏称 T-16 残差两处（`TS2352@295`／`TS2322@302`）根因是「信封四类型原为 **interface**、拿不到隐式索引签名，已转 **type 别名**」。
我**不复跑他的 monorepo**（原因见《S1前四项裁定与回执》§五），改为**独立做最小复现**——直接把他的根因命题拿出来单测。

## 一 方法（可复跑）

1. 装**仓内声明的同一版本** TypeScript（`package.json`：`"typescript": "^6.0.3"` ⇒ 取 **6.0.3**）；
2. 最小复现文件（interface vs type 别名，赋给 `Record<string, unknown>`）；
3. 以 `--strict --exactOptionalPropertyTypes` 跑 `--noEmit`。

```bash
# 复现文件内容（8 行核心）
interface Iface { a: string; b: number }
type Alias = { a: string; b: number };
declare const i: Iface;
declare const al: Alias;
const r1: Record<string, unknown> = i;    // ← 预期报错
const r2: Record<string, unknown> = al;   // ← 预期通过
declare const rec: Record<string, unknown>;
const t1: Iface = rec as Iface;           // ← 预期报 TS2352
```

## 二 结果：**根因命题成立，且两个错误码都复现**

```
tmp/ts/repro.ts(11,7): error TS2322: Type 'Iface' is not assignable to type 'Record<string, unknown>'.
  Index signature for type 'string' is missing in type 'Iface'.
tmp/ts/repro.ts(17,19): error TS2352: Conversion of type 'Record<string, unknown>' to type 'Iface' may be a mistake…
  Type 'Record<string, unknown>' is missing the following properties from type 'Iface': a, b
```

| 命题 | 实测 | 判定 |
|---|---|---|
| interface 类型**拿不到**隐式索引签名 ⇒ 赋 `Record<string, unknown>` 失败 | **TS2322**「Index signature for type 'string' is missing」 | **成立** ✓ |
| 改成 **type 别名**（对象字面量类型）即可 | 无错误 | **成立** ✓ |
| 反向转换的报错码 | **TS2352** | **与他点名的错误码一致** ✓ |

⇒ **他给出的根因与修法方向被独立验证**；两个错误码（TS2322／TS2352）都在最小复现里出现了。
