## 一、结论（三句）

1. **判定标准其实只有一套**——"在有契约含义的字段上，取值是否已按口径字典落到规范形态"。此前三个数对不上，**差异全部来自分母与样本，不是标准本身**（另加一类 `text` 噪声）。
2. **主口径从此固定**：标准化覆盖率 = `standardized=true` 的**非 text 有值字段** / **非 text 有值字段**。权威批（31 份 / 606 字段）实算 = **229 / 229 = 100%**。
3. **`text` 字段的 `standardized` 键无契约含义**（沿用 D13-C2 裁决）→ **不入分母、不上屏**；**弃权字段不得标 `true`**（标了就是数据卫生缺陷）。

## 二、定义与适用范围（消费侧照此实现）

| 项 | 规定 |
|---|---|
| **`standardized` 的语义** | 该字段**取值**是否已按口径字典落到规范形态（单位/量纲/分母/币种/时间格式），且与 `raw_value` 不矛盾。它描述**标准化状态**，不描述"抽取对不对" |
| **适用范围** | **有值字段**（`value` 非空）**且 `unit ≠ text`** |
| **不适用** | ① 弃权/空值字段（`not_mentioned` / `not_applicable` / `not_disclosed` / `unreadable`，以及无值的 `needs_review`）——没有值可标准化；② `unit: text` 字段——键无契约含义 |
| **标注完整性** | 有值字段**必须**带布尔 `standardized`；缺键或非布尔 = 缺陷（单列，不进分母） |
| **禁止** | 弃权字段标 `standardized: true`；消费方读取 `text` 字段的该键 |

**两个指标必须分列**（不得相加、不得互相替代）：

| 指标 | 定义 | 对应目标 |
|---|---|---|
| **标准化覆盖率** | `standardized=true` 的非 text 有值字段 / 非 text 有值字段 | 无（自建口径） |
| **标准化正确率** | 非 text 有值字段中 `value` 与 Gold 规范值一致的比例 | **≥98%**（总规划）——目标只挂这一项 |

**为什么正确率可以用值层承载**：`value` 就是规范化之后的取值（口径字典的落点）。D3-PLD-004 的 `364`（应为 3,640,000，万股表头单位未传导）正是**值层**抓出来的——值层一致即标准化正确。
