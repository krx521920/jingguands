## 缺陷

| 位置 | 事实 |

| `evaluation/D11/firsttest-envelopes/D4-PLD-008.json` → E01 → `announcement_date` | `status: not_mentioned`、`raw_value: null`、`value: null`、`provenance: []`，却标 **`standardized: true`**；note 写"出处为报备/备查文件落款日期而非公告披露日 → not_mentioned" |

**性质**：弃权字段（没有值）标 `standardized: true` 是**语义错误**——消费者若照字面读，会认为"该字段已标准化"。它不是判断口径分歧，是字段卫生问题（note 改了 status，`standardized` 没跟着翻）。

**影响面**：不进任何分母（按新裁定，弃权字段不参与标准化统计），所以成绩不受影响；但会误导消费方，且**新检查器会一直报它**。

**建议修法**：把该字段 `standardized` 置 `false`（或按契约允许的话去掉该键），**并只修这一处**——首测冻结信封是证据，除非确有语义错误，不做批量重造；改完请在提交说明里写"仅此一处、原因、影响面 0 分母"。
