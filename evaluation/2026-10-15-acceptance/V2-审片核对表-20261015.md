## 四 MP4 到手后立即跑的命令

```bash
# 规格与时长（快）
ffprobe -v error -show_entries format=duration,size -show_entries stream=codec_name,width,height,r_frame_rate -of json <mp4>
sha256sum <mp4>                       # 记进交付 SHA 清单

# 抽帧核对关键画面（每分镜抽 3 帧）
ffmpeg -i <mp4> -vf fps=1/20 /tmp/f_%03d.png

# 字幕/数字核对：把字幕文本导出后与白名单逐条比对（大小写/千分位归一）
ffmpeg -i <mp4> -map 0:s:0 /tmp/subs.srt   # 若有内嵌字幕
```
**判据**：规格 ≤5 min / ≤500 MB、1080p/30fps/H.264/AAC；**两台设备完整播放**（S1 要求）；**片尾提交号 = 冻结锚**。
