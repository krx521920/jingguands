新增预期在调用前保存于 [heldout/gold.json](heldout/gold.json)，封存值见 [pre-call-lock.json](heldout/pre-call-lock.json)。[live/results.json](live/results.json)逐项列出预期与实际，[browser-timings.json](live/browser-timings.json)绑定页面计时截图与调用记录。运行 `python evaluation/2026-10-18-closure/verify.py` 可离线复核，不发生模型费用。

[abstention-review.json](abstention-review.json)保留逐文档、事件、字段的复核决定与原始输入摘要；[gold-corrections-v1.4.json](gold-corrections-v1.4.json)是显式修订层，旧 Gold 和旧验收记录保持不变。

交付 MP4 使用真实页面分段采样、中文合成语音与字幕，等待片段经过剪辑。它不是连续桌面录屏，也不冒充真人讲解。文件随最终运行包交付；片长与校验值见包内 VIDEO-INFO.json。

仍然存在的能力边界：扫描 OCR 未实现；任意新文档自动跨文档识别没有完成独立评测；新增三份样例不足以证明全量泛化；没有独立人工盲测。页面配对与核验使用保存的开发集结果，受控用例单独标注。按此范围可用于课程原型演示，不能宣传为无条件生产系统。

原始公告 PDF 仅在本地交付包保留；公开仓库保存官方 URL、哈希与解析结果，遵守既有不二次公开分发原始公告的规则。默认 verify.py 可检查其余记录；加 `--require-pdf` 要求三份原文件也齐备。
