## 二、但我修了一个真问题：守卫过时（`shot_parity3` 挂了）

### 现象

```
Page.wait_for_selector: Timeout 45000ms exceeded.
  - waiting for locator(".mx-parity-card") to be visible
    89 × locator resolved to 3 elements. Proceeding with the first one
```

**元素存在 3 个，却一直等不到 "visible"。**

### 根因（你的新设计导致，我的守卫没跟上）

你把"实际对照三层"收进了**默认折叠的 `<details>`**：

```
<summary>详细对照与历史统计 · 展开查看来源与限制</summary>
open = false，details 高度 68px
```

Playwright 的 `visible` 判定要求祖先 `<details>` 处于 `open` ⇒ 必然超时。
**这是守卫的假设过时，不是页面缺陷**（实测卡片 379×291、`display:block`、零控制台错误、点开就正常）。

### 修法

1. 先断言折叠层存在且带`summary` 引导文案（**把"默认折叠"这个设计意图锁住**，防以后误删）；
2. 守卫代为展开 `details`；
3. 再按 `state="visible"` 断言卡片。
