# 换算用例 v0.1

以下均为**合成示例**，只验证标准化函数；不是公告抽取结果。机器可读输入与关键输出存放在 `../tests/fixtures/normalization_cases.json`，对应测试为 `../src/normalization/__tests__/normalization.test.ts`。标准单位分别为元、股、%。`value` 是十进制字符串，`null` 表示无可用数值。

| 编号 | 输入（合成原文 → 已确认字段） | 预期输出 | 核验重点 |
| --- | --- | --- | --- |
| 1 | “交易金额为 12.34 元” → `12.34 元`，单次 | `12.34 元`，`present/exact/single` | 元不变 |
| 2 | “金额约 1.25 万元” → `1.25 万元`，单次 | `12500 元`，`present/approx/single` | 万元换算，约数保留 |
| 3 | “金额不超过 0.15 亿元” → `0.15 亿元`，累计 | `15000000 元`，`present/at_most/cumulative` | 亿元换算，上界不可当精确值 |
| 4 | “本次质押 123 股” → `123 股`，单次 | `123 股`，`present/exact/single` | 股不变 |
| 5 | “累计质押 1.25 万股” → `1.25 万股`，累计 | `12500 股`，`present/exact/cumulative` | 万股换算、累计标记 |
| 6 | “本次变动 -0.00000001 亿股” → `-0.00000001 亿股`，单次 | `-1 股`，`present/exact/single` | 亿股换算、负方向、整数股 |
| 7 | “本次质押占公司总股本 2.5%” → `2.5%` | `2.5%`，分母=`total_share_capital`，单次 | 比例数值是百分点，不做乘百 |
| 8 | “累计质押占该股东所持股份 20%；交易金额占期末归母净资产 3.25%” → 两个 `ratio` | `20%`/`3.25%`，分母分别=`holder_shares`/`net_assets` | 两种分母必须分开保存 |
| 9 | 金额原文未提及；“本次质押股数为 0 股” | 金额=`null/not_mentioned`；股数=`0/explicit_zero` | 缺失不等于零 |
| 10 | 扫描件的比例单元格无法辨认 | 比例=`null/unreadable` | 无法读取不等于未提及，不猜数字 |

`at_most` 表示含上界。第 3 例的 `15000000` 是上限，不代表已经发生该金额。第 8 例是一组用例包含两个不同分母的输入，测试将逐条比对。第 9 例同样包含两个输入，以直接验证 `null` 和明确零的差异。

离线运行：进入 `finance-agent/` 后执行 `npm test`。测试只使用 Node.js 24 内置的 TypeScript 支持、测试运行器和断言模块，不需要安装依赖或访问网络。若目标环境低于 Node.js 24，需先约定团队已有的离线 TypeScript 执行方式；不要在线拉取包。
