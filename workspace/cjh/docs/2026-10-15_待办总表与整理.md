## 8. 本轮推送踩的三个坑（供接手）

1. **沙箱会拦 `~/.ssh/config` 的读取** ⇒ git 读不到「`github.com` → `ssh.github.com:443`」规则，回落到默认 **22 端口**，`ssh: connect to host github.com port 22: Connection timed out`。**与梯子无关**，`git fetch/push` 需绕过沙箱执行。
2. **过期锁 `.git/dsh-lefthook-install.lock`** 会让 `pnpm install` 的 postinstall（`install-lefthook.mjs`）失败 ⇒ `pnpm run typecheck` 连带失败 ⇒ pre-push 报「假失败」。删掉该锁即可。
3. **`pre-push` 的 typecheck 是仓库级闸门**，检查整个 monorepo（不只我方 `workspace/cjh/`）。判断「是不是我引入的」要看 `git diff <远端sha> HEAD -- <报错路径>` 是否为空，而不是看错误数量。
