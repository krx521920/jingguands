> 适用范围：`jingguands` 仓库（cjh-workspace 分支）＋ 团队每日协作。来源：仓库 AGENTS.md / docs/development.md / lefthook 配置 ＋ 计划表协作规则页。

## 1. 分支与仓库

| 规则 | 内容 |
|---|---|
| 工作分支 | `cjh-workspace`（基于 `origin/develop` @ 477b4f4）；一切改动只在此分支提交 |
| 上游分支 | `develop` 为集成分支，`master` 为主干（重型 CI 只认 master push） |
| 禁止 | 裸 `--force` 推送；只允许 `--force-with-lease`，远端有变动即中止 |
| 推送前 | pre-push 钩子自动跑 `pnpm run typecheck`；平时只跑与改动相关的最小检查（CI 管全量） |
| PR | 打标签：1 个 `kind/*` ＋ 相关 `area/*`；stack PR 用 `gh stack` 流程 |
| 钩子 | Lefthook 已装：pre-commit 查配对记录/Oxlint/空白/末尾单换行；vendor 改动须同步 manifest |
| 环境 | node ≥22.19；corepack 强制 pnpm@11.7.0（仓库锁定）；密钥放根 `.env`（已 gitignore），**永不提交凭据** |
| **提交纪律** | **任何 git commit / push 必须等领导（用户）明确说"提交"才执行；领导未发话，一律只在工作区改文件、不进 git**。日常可做：改文件、跑检查、跑构建；冻结动作：commit / push / merge / rebase |

## 2. 工作区文件编辑规则

1. **改自己链路的文件**：我只改网页/展示/演示/交付相关代码与材料（页面组件、导出、演示脚本、视频/PDF 材料）；不碰魏（架构/抽取）、张（解析/出处）、宗（评测资产）、方（口径规则）的主战场文件，需要改动时走交接沟通。
2. **不动 `vendor/`**：vendored 代码是钉死的上游副本，任何修改走 vendor/README.md 的同步流程。
3. **不碰封存测试资产**：30 份单文档＋20 组跨文档封存测试由宗博文保管，首测前不交开发；**不得预看、不得覆盖首测输出**。
4. **不复制底层解析代码**：新能力一律复用共享接口（魏的插件接口），防重复实现漂移。
5. **文件卫生**：文件末尾恰好一个换行（pre-commit 强制）；无个人机器绝对路径依赖（D13 复现要求）。
6. **模拟/真实显式分离**：页面消费模拟数据必须标"模拟"，不得计入真实成绩；D3 起端到端验收不能用模拟代替。
7. **材料共写**：PDF/视频由每人供稿自己模块的文字与证据，我只做整合；不把交付阶段全压给一人。
8. **失败诚实**：不能读/证据不足时展示"无法读取/待复核"，不填 0、不猜数、不默默反转方向。

## 3. 每日协作规则

| 项 | 规则 |
|---|---|
| 每日共同目标 | 一天 1 个可展示的系统结果，按 数据→解析→抽取→计算→展示 贯通 |
| 13:00 合流 | 交最小可用中间产物；接口未齐先用冻结样例推进 |
| 17:30 联调 | 全员同一版本、同一场景演示；每人展示自己产物被用到 |
| 阻塞 20 分钟 | 无法推进即发起结对；其他人继续并行；不得临时改接口破坏冻结结构 |
| 完成判定 | "已接入"＝有产物＋有证据＋进入当天共同场景；写完未接入算"待接入" |
| 失败处理 | 未达标保持不通过，记录差距/根因/次日支援；不靠投票判通过 |
| 轮值主持（D5、D10） | 只做协调和记录，工作包不归零，不是唯一验收人 |
| 独立评测 | 宗博文不改被评测业务代码；首测与修后回归分开，回归不得冒充盲测 |
| 标注争议 | 先记录，必要时请指导老师复核；修订留痕并按统一口径重算 |

## 4. 交接对象与接口（我的上下游清单）

**我消费的**：
- 魏文宇 → 事件 JSON 接口、真实调用结果、批量任务状态、失败隔离信号、缓存/版本信息
- 张智博 → 页面块、block_id、页码/区域坐标、证据 ID、原文跳转、文件唯一标识
- 方轩诚 → 标准化值、判定解释文案、报告数据结构、口径异常说明
- 宗博文 → 开发样例、真实成绩、误报案例、统计核对、答辩追问题

**我供给的**：
- 向魏/张 → 页面所需字段清单、断链/错位/超时等前端缺陷、批量页面状态
- 向全员 → 统一演示入口、导出文件、运行记录、材料整合稿
- 向宗 → 页面与命令行一致性证据、导出回归结果

**阻塞升级路径**：对应上游成员 → 结对 20 分钟 → 轮值主持人记录 → 当日未解写入"未解问题"，次日优先。

## 5. 红线（违反即返工）

- 不提交凭据/API key；不提交大文件（视频走交付包不走 git）
- 不用模拟输出冒充真实抽取成绩；不改成绩凑通过
- 不在评审/首测前偷看封存测试；不覆盖首测原始输出
- 不裸 `--force`；不跳过钩子提交（不 `--no-verify`）
- 演示与源码必须同版本
