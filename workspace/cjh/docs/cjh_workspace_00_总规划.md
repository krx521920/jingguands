# 陈家浩 · 总规划（14 天冲刺 + 21 天视角）

> 来源：`team_plan_14days.xlsx`（五人并行协作看板）＋ 仓库 `jingguands` 规范。
> 冲刺窗口：**2026-09-27（D1）～ 2026-10-10（D14）**，日投入 4–6 小时/人。
> 本文以"陈家浩"角色为主体；全队通用规则见 `01_规则.md`，执行跟踪见 `02_临时.md`。

---

## 1. 项目与团队

**项目**：可信公告事件提取与跨文档核验智能体（A 工作流：单文档抽取；B 工作流：跨文档同事件对齐与矛盾核验）。

**五人分工**：

| 成员 | 主攻 | 与陈家浩的关系 |
|---|---|---|
| 魏文宇 | 架构 / 抽取 / 编排 | 上游：给我接口、结果 JSON、批量状态；我向他反馈页面所需字段、断链错位 |
| 张智博 | 解析 / 表格 / 出处 | 上游：给我页面块、坐标系、证据 ID、原文跳转；我与他核对出处展示 |
| 宗博文 | 样例 / 标注 / 独立评测 | 上游：给我样例、真实成绩、统计核对；我向他核对材料数字；**不改被评测代码** |
| 方轩诚 | 口径 / 标准化 / 核验 | 上游：给我判定解释文案、报告字段；我与他核对展示文案 |
| **陈家浩** | **网页 / 展示 / 演示 / 交付整合** | 链路终点：消费四人产物 → 页面 → 导出 → 报告 → 视频 |

**轮值主持**：顺序 魏→张→宗→方→陈 循环；我担任 **D5（10-01）、D10（10-06）**。主持只做协调和记录，自己的工作包不减。

| 时点 | 事项 | 我的动作 |
|---|---|---|

## 4. 21 天视角（D15–D21 缓冲周，建议）

表格排期为 14 天；若窗口为 21 天，D15–D21 不新增功能，专用于：

1. **缓冲修复**：消化 D11 首测与 D12 回归暴露的长尾问题（展示/导出/性能）；
2. **材料打磨**：计划书 PDF、演示视频按答辩反馈迭代，补齐引用出处截图；
3. **复现加固**：再组织 1–2 次非作者干净环境复现，覆盖更多机器环境；
4. **答辩预演**：按宗博文设计的追问清单做至少 2 轮模拟答辩；
5. **封版纪律**：D14 之后只允许修阻断级缺陷，改动必须登记版本与理由。

## 5. 验收指标（统一评测，团队共用）

字段抽取 ≥90%｜标准化 ≥98%｜错误填充率 ≤5%｜格式合规 100%｜出处命中 ≥95%｜矛盾召回 ≥85%｜矛盾误报 ≤10%｜重复运行一致率 ≥98%｜20 页文本公告 ≤90 秒。首测（封存 30 单文档＋20 跨文档）与修后回归分开保存；开发成绩不得写成独立测试成绩。

## 6. 交付清单（D14）

源码 + 依赖 + 配置说明 + 样例 + 日志 + 评测附件 + 计划书 PDF + **MP4 ≤5 分钟且 ≤500MB**；展示与源码同版；未达标项明示。
