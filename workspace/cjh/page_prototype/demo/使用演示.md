# 使用演示 · 完整走一遍

> 目标：5 分钟内从零跑起来，并亲手完成一次"添加新数据集"的扩展。

## 演示 1：启动并浏览三栏页面

```bash
cd workspace/cjh/page_prototype
node server.js
```

浏览器打开 `http://127.0.0.1:8642`，应看到：

1. 顶部标题旁有 **"模拟数据"** 紫色徽章，下方紫色横幅常驻（模拟/真实分离红线）；
2. 左栏"上传"：数据集下拉已自动列出 `pledge`、`share_change`，且默认加载了 `pledge`；
3. 中栏"抽取结果"：两张事件卡片——
   - `evt-0001`：5 个字段，绿色"成功"徽章，每个字段后面有蓝色"证据 ev-xxxx"链接；
   - `evt-0002`：橙色"待复核"徽章，`pledgee` 字段单独显示灰色"无法读取"（status_override 生效）；
4. 右栏"证据"：3 条证据（block_id / 页码 / 原文摘录）；
5. **点中栏任意"证据 ev-xxxx"链接** → 右栏对应证据卡高亮并滚动到视野中央（出处联动）；
6. 切换左栏下拉为 `share_change` → 页面整体刷新为股权变动事件（演示 3 已预置）。

## 演示 2：本地文件上传

1. 左栏点击虚线框（或拖入文件），选一个本地 `.txt`；
2. 出现文件条目 + 橙色"待复核"徽章 + "等待解析（D2 接入）"提示；
3. 打开浏览器控制台（F12），能看到 `[D1 占位] 本地读取 xxx.txt：N 字符`——真实解析对接张的产物，属 D2。

## 演示 3：扩展——添加一个新数据集（零代码）

1. 新建 `data/bank_guarantee.json`，粘贴以下内容：

```json
{
  "run_id": "mock-run-0003",
  "schema_version": "0.1",
  "data_mode": "simulated",
  "source_file": { "file_id": "mock-file-003", "filename": "担保公告样例.txt", "parse_status": "success" },
  "events": [
    {
      "event_id": "evt-0201",
      "event_type": "guarantee",
      "status": "success",
      "fields": {
        "guarantor":     { "value": "模拟公司丁", "evidence_id": "ev-0201" },
        "guarantee_amt": { "value": 80000000, "unit": "元", "normalized": 80000000, "evidence_id": "ev-0201" }
      }
    }
  ],
  "evidences": [
    { "evidence_id": "ev-0201", "block_id": "blk-0030", "page": 1, "bbox": null, "quote": "（模拟原文）公司丁为……提供 80,000,000 元担保……" }
  ]
}
```

2. **不用重启**：刷新浏览器，左栏下拉自动多出 `bank_guarantee`，选中即渲染；
3. `guarantor / guarantee_amt` 没在字段词典登记 → 页面直接显示原始字段名（优雅降级，不报错）；
   想显示中文：在 `public/js/render/results.js` 的 `FIELD_TEXT` 加 `"guarantor": "担保人"` 即可。

## 演示 4：切换真实接口（对接魏的产物）

```bash
# PowerShell（示例：上游跑在本机 9000 端口）
$env:DATA_SOURCE = "remote"
$env:REMOTE_API_URL = "http://127.0.0.1:9000/result"
node server.js
```

页面操作完全不变——前端只认数据契约（`docs/API.md` §3），上游返回同样结构即自动渲染，`data_mode: "real"` 时横幅消失、徽章变绿"真实数据"。

## 演示 5：接口自检（可选）

```bash
curl "http://127.0.0.1:8642/api/datasets"
curl "http://127.0.0.1:8642/api/result?dataset=pledge"
```

返回 JSON 即链路通。页面与接口同源同版本，17:30 联调时"页面与命令行结果一致"可以直接对照这两个返回。
