## 演示 1：启动并浏览三栏页面

```bash
cd workspace/cjh/page_prototype
node server.js
```

浏览器打开 `http://127.0.0.1:8642`，应看到：

1. 顶部标题旁有 **"模拟数据"** 紫色徽章，下方紫色横幅常驻（模拟/真实分离红线）；
2. 左栏"上传"：数据集下拉已自动列出 `data/` 下全部数据集（当前 10 个：2 个 mock + 1 个上游合成 + 1 个多事件合成 + 6 个魏的真实 run），默认加载 `pledge`；
3. 中栏"抽取结果"：事件卡片 + 字段表，每个字段带独立状态徽章（字段级状态，不继承事件级）；
4. 右栏"证据"：证据列表（出处类型/页码/表格单元格号/原文摘录）；
5. **点中栏任意"证据 ev-xxxx"链接** → 右栏对应证据卡高亮并滚动到视野中央（出处联动）。

## 演示 2：本地文件上传（入口占位，口径说明）

1. 左栏点击虚线框（或拖入文件），选一个本地文件 → 文件条目 + "待复核"徽章；
2. **口径**：上传栏是入口占位——真实解析在张智博的 finstruct 链路完成，页面直接消费解析后的成品 run（见演示 4），上传解析不在本页面做。

## 演示 3：扩展——添加一个新数据集（零代码）

1. 新建 `data/bank_guarantee.json`（内容见 `demo` 旧版或任一 mock 文件结构：`schema_version + data_mode + source_file + events[] + evidences[]`）；
2. **不用重启**：刷新浏览器，下拉自动多出 `bank_guarantee`，选中即渲染；
3. 未在 `FIELD_TEXT` 登记的字段 → 页面直接显示原始字段名（优雅降级）；
4. 上游格式也能直接放：把方口径的标准化记录（`bridge: "fang-normalization-v0.1"`）或魏的事件信封（`wei-event-envelope-v0.3`）存成 json 丢进 `data/`，server 读数自动过转接口，未知格式透传留痕不猜测。

## 演示 4：统一演示样例 · D4-PLD-001 全链路（17:30 联调主线，领导已拍板）

同一条公告在四方的完整链路，全用现成产物、无需新造数据：

| 环节 | 产物 | 位置 |
|---|---|---|
| 原文 | D4-PLD-001.pdf | 张 `sample/D4/raw/` |
| 解析 | D4-PLD-001.parse.json | 张 `sample/D4/parse/` |
| 抽取 run | `batch-20260930T095256`（10/10 成功） | 魏 `runs/` |
| 标准答案 | D4-PLD-001.envelope.json | 宗 `evaluation/D4/dev/gold/` |

页面操作：左栏选 `wei_real_PLD001_3ev` 加载 → 三张事件卡片（多事件落地实证）→ 36 个"成功"+ 3 个"未提及"+ 3 个"待复核"字段级状态。

## 演示 5：异常状态汇总条（D4 交付）

加载 `wei_real_PLD001_3ev` 后，结果栏顶部出现异常汇总条：

1. 按状态 chip 计数（未提及 3 · 待复核 3 …）；
2. **点击任一 chip** → 循环定位到对应字段行 + flash 高亮（异常行淡黄底）；
3. 完整性断链时显示红色警告条（有值无出处/引用缺失/cell 证据不全），仅提示时黄色。

## 演示 6：JSON / CSV 导出（D3 交付）

1. 中栏卡片右上或结果区点击 **导出 JSON / 导出 CSV**；
2. JSON 与 `/api/result` 逐字节一致（所见即所得）；CSV 每字段一行、18 列含出处块类型/表格单元格号/quote，UTF-8 BOM（Excel 直接打开不乱码）；
3. 命令行等价：`curl "http://127.0.0.1:8642/api/export?dataset=wei_real_PLD001_3ev&format=csv"`。

## 演示 7：direction 与扫描降级（D4 交付）

1. 加载 `wei_real_PLD005_release` → E02 卡片带橙色 **"解除质押"** 徽章（direction=release）；
2. 加载 `wei_real_D4_scan` → 14 个字段全部灰色"无法读取"（扫描件诚实降级，integrity 零误报）；
3. 张 schema 的 `scan_region+degraded` 降级块路径也已支持（amber 描边 + 降级原因中文），两种实现页面兼容。

## 演示 8：切换真实接口（remote 模式）

```powershell
$env:DATA_SOURCE = "remote"
$env:REMOTE_API_URL = "http://127.0.0.1:9000/result"
node server.js
```

前端零改动——上游返回契约对象或上游格式均自动处理，`data_mode: "real"` 时横幅消失、徽章变绿。

## 演示 9：接口自检

```bash
curl "http://127.0.0.1:8642/api/datasets"
curl "http://127.0.0.1:8642/api/result?dataset=wei_real_PLD001_3ev"
curl "http://127.0.0.1:8642/api/export?dataset=pledge&format=csv"
```

返回 JSON/CSV 即链路通。页面与接口同源同版本，联调时"页面与命令行结果一致"直接对照。
