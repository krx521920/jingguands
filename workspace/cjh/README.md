**现场导入/使用须知（步骤 7 落地，评审现场照此操作）**：

- **现场导入只收 `.json` 信封文件**——页面**不做在线 PDF 抽取**。要导PDF，
  须先经张智博的 DocumentIR 解析、再由魏文宇的抽取管线产出信封，页面只消费信封。
  上传件会经 `bridge/contract_validate.js` **机检**：缺 `run_id`/`is_mock`/`source`/`run_meta`
